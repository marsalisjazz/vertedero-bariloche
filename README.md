# Vertedero Bariloche

Juego pixel art del vertedero de Bariloche. La carpeta `public/` es el juego ya armado (un solo `index.html` con todo adentro, más el manifiesto, el service worker y los íconos para instalarlo como app).

Cloudflare lo publica solo con cada cambio en `main`, en https://vertedero-bariloche.marsalis-jazz.workers.dev. El APK de Android abre esa dirección, así que se actualiza sin instalar nada nuevo.
